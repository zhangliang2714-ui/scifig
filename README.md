# 科研机制图重构 Skill

`scientific-schematic-reconstruction` 是一个将 AI 生成图片、参考图片或已有科研示意图，拆解并使用 Blender、SVG 和 Python 等工具进行科学化重构的 Codex Skill。它把不可编辑、结构不严谨或比例不适合项目书的 AI 图片，转换为可解释、可编辑、可复现的科研机制图。

## 适用场景

- 根据参考图片或 SVG 重构科研机制图；
- 将 AI 生成的科研图片拆解为可重构的结构、流程和图形资产；
- 使用 Blender 补充晶粒、纤维、节点、烧结颈和第二相等三维模型；
- 将复杂总图拆分为多个科学语义区域；
- 判断哪些区域适合 SVG，哪些区域需要 Blender 三维建模；
- 重构纤维、晶粒、配位网络、局域有序、第二相、孔隙、界面和裂纹等结构；
- 将独立模型或数据图嵌入项目书总图；
- 统一中文项目书中的字体、字号、线宽、颜色和版式；
- 优化过宽的数据图，处理分面、共享坐标轴和断轴布局。

## 基本使用

安装后，可以直接在 Codex 中调用：

```text
使用 $scientific-schematic-reconstruction 重构这张科研机制图。
```

典型任务是：提供一张 AI 生成的科研图片，要求 Skill 先分析图片中的科学区域，判断哪些部分用 SVG 重画、哪些部分用 Blender 建模，再将各部分重新组合成项目书风格的可编辑 SVG。

也可以直接描述任务，例如：

```text
请先拆分这张图，判断哪些区域用 SVG、哪些区域用 Blender 建模，先做线框再逐区嵌入。
```

## 推荐工作流程

1. 明确图的核心科学结论和阅读顺序；
2. 将总图切分为语义区域并标出目标尺寸；
3. 建立线框、标题、箭头和图片占位框；
4. 判断每个区域使用 SVG、Python、Blender 或已有实验图片；
5. 先单独制作和预览三维模型，再嵌入总图；
6. 统一字体、颜色、线宽、视角和比例；
7. 在最终使用尺寸下检查科学含义、可读性和文件完整性。

## 工具分工

- **SVG**：文字、箭头、流程框、二维网络、简单纤维、界面和图例；
- **Python**：有明确数据、坐标轴或断轴需求的定量图；
- **Blender**：晶粒密排、纤维交叉、烧结颈、第二相颗粒和具有体积遮挡关系的结构；
- **透明 PNG**：Blender 模型的渲染资产；
- **已有图片**：显微照片和实验装置图，仅进行必要的全局裁切和版式调整。

## 输入材料

建议提供：

- 参考图片或 SVG；
- 项目书正文或图注；
- 每个区域想表达的科学含义；
- 最终画布和嵌入位置；
- 中文字体、字号和颜色偏好；
- 必须保留或必须修改的区域。

## 输出内容

通常包括：

- 可编辑的总图 SVG；
- 必要的独立 SVG 或透明背景 3D 资产；
- 最终尺寸 PNG 预览；
- 可复现的生成或嵌入脚本；
- 关键结构修改和仍需确认的科学假设说明。

## 重要原则

- 先切分和规划，再精细绘制；
- 不直接非等比压缩含有文字、坐标轴或晶格的图；
- 局域有序、第二相、晶界孔隙和缺陷必须使用不同的视觉表达；
- 配位网络要体现中心、配体和桥联关系，不能用随机线团替代；
- 多晶结构应搭接或密排，孔隙应位于晶界或三叉结；
- 每个模型先单独预览，确认后再嵌入总图；
- 默认不覆盖原文件，每轮修改保留新版本。
