# 可复用Blender模板目录

本目录用于保存经过参考图对照验收的 `.blend`、Geometry Nodes组和参数化脚本。

建议模板命名：

```text
polymer_fiber.blend
coordination_network.blend
packed_grains_with_boundary_pores.blend
local_order_and_second_phase.blend
sintered_fiber_node.blend
```

每个模板应同时包含固定相机、固定光照、透明背景渲染设置、固定随机种子和参数说明。未经过单独预览及叠加对照的模型，不放入正式模板目录。
