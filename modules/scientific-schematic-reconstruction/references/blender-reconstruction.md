# Blender参考图约束重构规范

Blender在本 Skill 中不是用来“凭文字生成一个大致像的3D图”，而是用来把参考图中已经确定的轮廓、方向、密度、接触关系和结构层级重新参数化。2D参考图通常不能唯一确定3D结构，因此无法从单张图片推断的深度、晶体学占位或真实配位数必须标记为“示意假设”，不能伪装成实验事实。

## 建模前的结构契约

每个模型开始前建立参数表：外轮廓、主方向、对象密度、结构层级、相机、光照以及不确定的示意假设。没有完成这张表，不进入复杂节点搭建。

## 固定渲染条件

优先使用正交相机或弱透视相机，并固定随机种子、相机、光照、色彩管理和透明背景。所有程序化分布必须可重复。

```python
SEED = 2714
CAMERA_TYPE = "ORTHO"
BACKGROUND_ALPHA = 0.0
RENDER_ENGINE = "BLENDER_EEVEE_NEXT"
```

## 五类可复用模板

- `polymer_fiber`：连续、实心、方向明确的聚合物前驱体纤维；
- `coordination_network`：金属中心、配体曲线和桥联连接；
- `packed_grains_with_boundary_pores`：晶粒搭接/密排，孔隙位于晶界和三叉结；
- `local_order_and_second_phase`：局域有序与具有独立边界的粗化第二相；
- `sintered_fiber_node`：真实接触纤维之间的烧结颈和节点融合。

## 参考图对照循环

每个模型输出原图、透明背景渲染图和50%透明度叠加图，依次修正外轮廓、主方向、密度、接触关系、材质和内部细节。
