# Nature/Science Figure Style Profile v1

Scope: this is a working design prior, not a verified universal style specification for Nature and Science flagship journals. For user-specific choices and corrections from rendered trials, follow [user-figure-conventions.md](../user-figure-conventions.md). In particular, default to panel letters without descriptive headings and judge whitespace by actual rendered text rather than generous spacing alone.

## Shared visual grammar

- Build figures as argument sequences: overview or mechanism first, quantitative evidence next, structural or microscopic validation after, and durability or comparison last.
- Use multi-panel grids with strict alignment, repeated margins, and short panel labels. Let one panel carry one claim.
- Keep the plotting field clean: restrained gridlines, minimal decorative borders, direct labels where they reduce legend search, and generous white space around annotations.
- Use a small semantic palette. Reserve saturated accent colors for the key comparison or active species; use neutral gray, black, and muted secondary colors for context and controls.
- Use consistent stroke hierarchy: axes and panel boundaries are lighter than data marks; arrows and mechanistic pathways are heavier and more directional.
- Prefer vector-like marks, simple geometric icons, clean microscopy crops, and physically meaningful color coding over ornamental gradients.

## Data-panel conventions

- Show observations, distributions, or uncertainty rather than only decorative summary bars.
- Use shared axes and units across comparison panels; avoid unexplained dual axes.
- Put statistical information close to the data and explain sample size, error definition, and normalization in the caption or legend.
- Use log scales only when the scientific range requires them and make the scale explicit.
- Combine curves, scatter points, bars, and image evidence only when each adds a distinct evidentiary role.

## Mechanism and structure conventions

- Start with a simplified overview, then expose the local structure or reaction pathway in an inset.
- Use controlled depth cues, soft shading, and limited perspective to distinguish layers, interfaces, pores, particles, and active sites.
- Keep arrows orthogonal or gently curved, avoid crossings, and place labels beside the object they identify.
- Use the same semantic color for an element or process across every panel and the schematic.

## Publication QA rules

- Check readability at the intended single-column or double-column width, not only on a large monitor.
- Export editable vector output when possible and a high-resolution raster fallback when required.
- Verify font embedding, Unicode/math rendering, line-weight consistency, color contrast, panel-label order, and caption-to-panel correspondence.
- Treat this profile as a prior for design decisions, not as a reason to copy another paper's data, claims, or exact artwork.
