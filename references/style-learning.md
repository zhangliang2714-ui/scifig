# Paper Figure Style Learning Template

Use this template when the user provides one or more reference figures.

Apply [user-confirmed figure conventions](user-figure-conventions.md), including the preference for panel letters without descriptive headings above the plots. Read the [corrected reference measurement example](zotero-figure-study/reference-measurements-2026-10-22.md) when extracting pixel geometry; keep crop-local and whole-image coordinates distinct.

## Visual inventory

- Journal, year, figure number, and stated scientific purpose
- Canvas aspect ratio and final-size assumptions
- Panel count, panel order, alignment, and whitespace rhythm
- Plot types, marks, coordinate systems, scales, units, and uncertainty encoding
- Typography: family, approximate sizes, weights, capitalization, and mathematical notation
- Palette: background, data series, semantic colors, contrast, and color-blind safety
- Strokes, borders, gridlines, arrows, callouts, icons, and annotation hierarchy
- Legend placement and label conventions

## Scientific inventory

- Claim supported by each panel
- Data or evidence shown versus inferred
- Comparisons, controls, normalization, and statistical summaries
- Which visual features are essential for interpretation

## Reusable output

Convert the inventory into a figure brief containing:

1. panel blueprint;
2. typography and spacing tokens;
3. palette with semantic roles;
4. mark and annotation rules;
5. export requirements;
6. a list of features that must remain faithful and features that may be adapted.

Do not treat a visual resemblance as evidence that the underlying analysis or data are equivalent.
